# UDAAN — Democratizing Sports Talent Assessment

UDAAN is an AI-powered sports talent assessment platform built for Smart India Hackathon (SIH), empowering athletes across India with accessible, camera-based fitness evaluation and personalized training support.

## Features

- **Authentication** — Secure signup/login
- **AI Fitness Assessment** — Real-time camera-based pose detection automatically counts reps for tests like sit-ups and push-ups
- **AI Assistant** — Chat with an AI coach for training guidance
- **Daily Tasks** — Track daily training tasks
- **Leaderboard** — Compare performance with other athletes
- **Profile & Progress Tracking** — View test history and performance trends
